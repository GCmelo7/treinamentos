# Árvores de links · Gabriel Melo

- `assets/` — motor (`tree.js`), visual (`tree.css`), foto e gerador de QR. Perfil e redes ficam no topo de `tree.js` (vale para todas as árvores).
- `index.html` — hub com todas as trilhas (`trails`).
- Nova árvore: copie `yazaki/` para `nova-pasta/`, edite só o `window.TREE` (título, data, agenda, abas e links) e adicione a trilha no `index.html` do hub.

Blocos disponíveis nas abas: `links`, `agenda`, `prompt`, `connect`. Campos de link: `title`, `sub`, `url`, `icon` (flask, spark, file, wand, gem, chat, compass, grid, dl), `tag`, `featured`, `cyan`.
